# Mis Proyectos

Listado de proyectos de desarrollo de software, prácticas de control de versiones y aplicaciones construidas durante mi formación en **Análisis y Desarrollo de Software (ADSO - SENA)**.

---

## 🚀 Proyectos Principales (Full-Stack & Web)

### 1. Eco Puntos
* **Descripción:** Plataforma orientada a la gestión ambiental y puntos de reciclaje.
* **Rol y documentación:** Elaboración de acta de constitución del proyecto y especificación de requerimientos bajo normas APA 7.ª edición.
* **Estado:** En desarrollo.

### 2. TaskMaster / API Node
* **Descripción:** Aplicación web full-stack para gestión de tareas con autenticación de usuarios (JWT) y documentación de endpoints con Swagger.
* **Tecnologías:** Next.js (App Router, Server Actions), Tailwind CSS, Node.js, Express, Prisma ORM y MySQL.
* **Estado:** En progreso.

### 3. Portales Web Responsivos (HTML & CSS)
* **Descripción:** Colección de sitios web multipágina con diseño adaptativo para escritorio y móviles.
* **Proyectos incluidos:**
  * **CinePortal:** Catálogo interactivo de películas.
  * **Tienda de Calzado:** E-commerce maquetado con CSS Grid y Flexbox.
  * **Portal de Conciertos:** Página informativa de eventos y boletería.
* **Tecnologías:** HTML5, CSS3 (Grid, Flexbox, `grid-template-areas`).

## 🛠️ Aplicaciones de Consola y Automatización

### 4. Biblioteca de Poemas (Node.js)
* **Descripción:** Aplicación de consola para administrar y consultar poemas mediante lectura y escritura de archivos locales.
* **Tecnologías:** JavaScript (Node.js), módulos personalizados, `fs` y `prompt-sync`.

### 5. Automatización de Inventarios (SAP & Excel)
* **Descripción:** Macro integrada para automatizar la extracción, cruce y ordenamiento de reportes de bodega.
* **Tecnologías:** Excel VBA, SAP GUI Scripting (`PMBODEGA`) y SQL Server Reporting Services.
